ATIVIDADE NO DISCORD (Rich Presence) - passo a passo
Importante: um site sozinho NÃO consegue mudar sua atividade do Discord. Este pequeno script roda no seu PC e faz isso.
Ele só funciona enquanto estiver aberto e com o Discord de COMPUTADOR aberto (não funciona só pelo celular/navegador).

1) Acesse https://discord.com/developers/applications > New Application.
   O NOME do app é o que aparece como "Jogando ___" (ex.: tutulindojogos).
2) Em General Information, copie o "Application ID".
3) Menu Rich Presence > Art Assets > Add Image(s): suba o icon.png desta pasta e nomeie como  icon  (minúsculo).
   (pode levar alguns minutos para aparecer)
4) Abra presence.py e troque CLIENT_ID pelo Application ID e SITE_URL pelo link do seu site.
5) Instale o Python (python.org) se não tiver e dê dois cliques em iniciar.bat.
6) No Discord: Configurações > Atividade > Privacidade da atividade > ligue "Compartilhar minha atividade".
   Se você tiver outro jogo aberto, o Discord mostra o jogo no lugar; feche o jogo para ver o site.
Obs.: os botões aparecem para as OUTRAS pessoas, não para você no seu próprio perfil.

PARA O SITE MOSTRAR A ATIVIDADE (Lanyard):
1) Entre no servidor https://discord.gg/lanyard
2) Copie seu ID do Discord (Configurações > Avançado > Modo desenvolvedor; depois clique com o botão direito no seu perfil > Copiar ID do usuário)
3) Cole em  const DISCORD_ID = ''  no começo do bloco "v7" do script.js do site e publique de novo.
